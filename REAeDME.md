# TaskFlow
### Gestión de tareas eficiente para equipos colaborativos

## Descripción
TaskFlow es una aplicación sencilla e intuitiva diseñada para organizar, asignar y realizar un seguimiento del flujo de trabajo de un equipo en tiempo real[cite: 1].

---

## Funcionalidades principales
* **Asignación de tareas:** Delega responsabilidades fácilmente entre los miembros del equipo.
* **Priorización:** Clasifica tareas por urgencia e importancia.
* **Notificaciones:** Recibe alertas de cambios de estado y fechas límite.

---

## Tecnologías utilizadas
* **Frontend:** HTML, CSS, JavaScript (React)
* **Backend:** Node.js, Express
* **Base de datos:** PostgreSQL

---

## Requisitos del sistema
* **Node.js:** Versión 18.0 o superior
* **NPM:** Versión 9.0 o superior
* **Git:** Para clonar el repositorio

> **Nota:** Asegúrate de tener configurada la variable de entorno `.env` antes de ejecutar el proyecto.
